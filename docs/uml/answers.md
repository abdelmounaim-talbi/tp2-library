
# TP 3 – Final Questions

## (a) What does left to right direction change? What does the arrow mean?

It changes the diagram layout from top-to-bottom to left-to-right.

`-->` means a directed association pointing toward the use case. `--` represents a simple association.

## (b) Did PlantUML detect the reversed extend relationship?

No. It displays the diagram but does not automatically detect the semantic mistake.

## (c) Give two advantages and two drawbacks of automatic layout.

Advantages:
1. Saves time.
2. Organizes elements automatically.

Drawbacks:
1. Layout may not be exactly what we want.
2. Lines can overlap and make the diagram difficult to read.

## (d) Compare PlantUML with Modelio.

| PlantUML | Modelio |
|---|---|
| Uses text code | Uses graphical tools |
| Easy to edit code | Easy to draw diagrams |
| Good Git comparison | Visual changes are harder to compare |
| Automatic layout | More control over positioning |

## (e) Why keep models in the same repository as the code?

It keeps the diagrams and source code together, makes changes traceable with Git, and keeps the documentation consistent with the project.
